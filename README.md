# می‌دار

همراه دورهمی برای مدیریت نوشیدن. وب‌اپ فارسی (PWA)، بدون سرور و بدون ثبت‌نام؛ همه‌ی داده‌ها فقط روی گوشی می‌ماند.

## مسیر برنامه
راه‌اندازی مرحله‌به‌مرحله (هر صفحه یک سؤال): تعداد نفرات ← اسم‌ها ← حال جمع ← لحن ← نوشیدنی و درصد ← فاصله ← برگشت ← آدم امن ← «آماده‌ایم» ← شروع مجلس.
بعد از شروع: تب‌های مجلس، کوکتل، سرگرمی، آدم امن و تنظیمات.

## انتشار روی GitHub Pages
1. همه‌ی فایل‌های این پوشه را (نه خود پوشه را) در ریشه‌ی مخزن آپلود کن؛ `index.html` باید کنار `sw.js` باشد.
2. Settings ← Pages ← Deploy from a branch ← `main` / `(root)` ← Save.
3. آدرس: `https://USERNAME.github.io/REPO/`

## نصب روی گوشی
- اندروید (Chrome): منو ← Install app.
- iPhone (Safari): Share ← Add to Home Screen.

## به‌روزرسانی
بعد از هر تغییر، در `sw.js` عدد `VERSION` را بالا ببر (مثلاً `meydar-v3`). نسخه‌ی فعلی: `meydar-v2`.

## یادداشت‌ها
- آستانه‌ها (سقف واحد استاندارد و سرعت) طراحی‌شده‌اند، نه استاندارد رسمی. برنامه میزان الکل خون را نمی‌سنجد.
- دستور کوکتل‌ها از فهرست IBA و دستورهای رایج است؛ میزان الکل تقریبی است.
- اشعار از حافظه نوشته شده و باید با گنجور تطبیق داده شود.
- لینک اسنپ و تپسی را قبل از انتشار یک بار باز کن.
- فونت‌ها (وزیرمتن و نوتو نسخ عربی) با مجوز OFL داخل پوشه‌ی `fonts` هستند.
