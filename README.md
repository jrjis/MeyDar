# می‌دار

همراه دورهمی برای مدیریت نوشیدن و حفظ حال مجلس. وب‌اپ فارسی (PWA)، بدون سرور، بدون ثبت‌نام. همه‌ی اطلاعات فقط روی گوشی خود کاربر می‌ماند.

## انتشار روی GitHub Pages
1. در GitHub یک مخزن (repository) جدید بساز، مثلاً `meydar`.
2. همه‌ی فایل‌های این پوشه را در ریشه‌ی مخزن آپلود کن (`index.html` باید کنار `sw.js` و `manifest.webmanifest` باشد). فایل `.nojekyll` را هم فراموش نکن.
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` و پوشه‌ی `/ (root)` ← Save.
4. بعد از یکی دو دقیقه آدرس `https://USERNAME.github.io/meydar/` فعال می‌شود.

## نصب روی گوشی
- **Android (Chrome):** منو ← «Install app» یا «Add to Home screen».
- **iPhone (Safari):** دکمه‌ی Share ← «Add to Home Screen». (فقط از Safari کار می‌کند.)

بعد از اولین بار باز شدن با اینترنت، برنامه بدون اینترنت هم کار می‌کند. فقط لینک‌های بیرونی (جست‌وجوی موزیک، اسنپ، تپسی) اینترنت می‌خواهند.

## وقتی فایل‌ها را تغییر دادی
در `sw.js` عدد `VERSION` را بالا ببر (مثلاً `meydar-v2`). وگرنه کاربرانی که قبلاً برنامه را باز کرده‌اند ممکن است تا چند بار باز کردن نسخه‌ی قدیمی را ببینند.

## ساختار
- `index.html`: خود برنامه (همه‌ی کد در یک فایل)
- `manifest.webmanifest`: نام، آیکون و حالت نصب
- `sw.js`: کار بدون اینترنت
- `icons/`، `fonts/`: آیکون‌ها و فونت‌های محلی (وزیرمتن و نوتو نسخ عربی، مجوز OFL)

## یادداشت‌های مهم
- اعداد و آستانه‌ها (سقف واحد استاندارد، سرعت در ساعت) طراحی‌شده‌اند، نه استاندارد رسمی. برنامه میزان الکل خون را نمی‌سنجد.
- اشعار از حافظه نوشته شده‌اند و باید با گنجور تطبیق داده شوند.
- لینک اسنپ (`snapp.ir`) و تپسی (`tapsi.ir`) را قبل از انتشار یک بار باز کن.
- نام و شمارهٔ «آدم امن» فقط در `localStorage` همان گوشی ذخیره می‌شود.
